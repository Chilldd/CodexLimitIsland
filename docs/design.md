# CodexLimitIsland · Deep Space Minimal

## 视觉设计规范 v1.1

### 1. 整体设计语言

设计关键词：**深黑、冷调、极简、精密、克制、微光**。

使用独立于桌面背景的深色主体，通过细微的明度差、文字排版和局部高光建立质感。

- 主体使用冷黑色，不采用纯粹的死黑。
- 边界极弱，不能出现明显白边。
- 内部卡片只比主体略亮。
- 不使用毛玻璃、背景模糊、液态折射效果。
- 不使用大面积发光和高饱和度渐变。

### 2. 配色系统

| 元素       | 色值      |
| ---------- | --------- |
| 主体顶部   | `#0E1117` |
| 主体底部   | `#080A0E` |
| 装饰强调色 | `#83D6DB` |
| 桌面端图标 | `#7A99AF` |
| 进度条轨道 | `#232A32` |

主体背景使用从 `#0E1117` 到 `#080A0E` 的纵向微渐变。

文字统一使用 `src/styles/tokens.css` 中的语义化 Token，不在组件内另建灰色体系：

| Token              | 色值      | 用途                                       |
| ------------------ | --------- | ------------------------------------------ |
| `--text-primary`   | `#F2F6FA` | 主标题、额度百分比、监控合计和重要结果数值 |
| `--text-secondary` | `#C9D3DC` | 正文、状态说明、模型名称、时间             |
| `--text-tertiary`  | `#92A0AD` | 分区标题、监控标签、多会话次级信息         |
| `--text-muted`     | `#82919E` | 重置提示、Token 辅助统计、弱化元数据       |
| `--text-accent`    | `#9BCAD4` | 选中标题、活动高亮和必要的强调文字         |

主标题采用柔和冷白，正文采用浅灰蓝，辅助信息采用中灰蓝。青色仅用于选中态、活动状态和必要的重点，不大面积用于普通正文。装饰强调色 `--accent` 与文字强调色 `--text-accent` 分开使用，避免文字优化改变图标、边框、进度条或趋势图的配色。

审批、额度异常和错误保留原有警告或错误语义色，不统一改为冷白色。

### 3. 字体系统

字体优先级：

`Inter → Segoe UI Variable → Segoe UI → Microsoft YaHei → sans-serif`

| 用途                 | 现有字号 | 字重    |
| -------------------- | -------- | ------- |
| 收缩态及展开态主状态 | 12px     | 600     |
| 项目 / 会话名称      | 12px     | 600     |
| 收缩态额度百分比     | 12px     | 600     |
| 额度卡片百分比       | 16px     | 600     |
| 额度卡片百分号及标题 | 13px     | 500–600 |
| 监控数值             | 10px     | 500–600 |
| 辅助说明、模型及时间 | 10–12px  | 400–500 |
| Token 统计           | 10px     | 400–500 |
| 重置提示             | 9px      | 400–500 |

排版规则：

- 英文与数字尽量使用 Segoe UI Variable。
- 数字使用等宽数字特性 `tabular-nums`。
- 保持现有字体族；会话行按下述两行结构分配空间与截断。
- 原有大写分区标题保留；如需微调字间距，控制在 `0.08em–0.12em`。
- 重要信息与小字号标签不使用 300 或更低字重；优先通过颜色和 400–600 字重建立层级。
- 不使用纯白正文、文字阴影或 `filter: brightness()` 间接提亮；现有字形内渐变扫光按第 8 节保留。
- 保持文案含义与截断方式；展开态按统一项目区域布局。
- 界面固定文案、提示与托盘菜单统一使用简洁英文；项目名称和模型标识保留来源值。

#### 3.1 对比度与渲染

- 常规正文和小字号标签以 WCAG AA `4.5:1` 为最低对比度目标；在主体、普通卡片、选中卡片和悬停背景下分别核对，不足时提高文字亮度。
- 基础文字使用不透明的语义色，不叠加 `opacity` 或改写为半透明 `rgba()` 降低亮度。既有展开收缩、状态切换动画及字形内扫光保留。
- 禁用态与非文本装饰沿用现有规则，不用文字 Token 顺带调整边框、图标或阴影。
- Windows WebView2 需检查 100%、125%、150% 缩放，确认字重变化没有导致意外换行、截断或布局偏移。

| 展开态顶部 | 弱化元数据                   | muted     | 400–500 |
| 活动信息区 | 分区标题                     | tertiary  | 600     |
| 活动信息区 | 当前动作、耗时               | secondary | 500     |
| 活动信息区 | 模型名称、Token 标签         | tertiary  | 400–500 |
| 活动信息区 | Token 数值                   | secondary | 500     |
| 多会话列表 | 正在运行的会话名称           | primary   | 600     |
| 多会话列表 | 已完成或中断的会话名称       | primary   | 600     |
| 多会话列表 | 会话当前状态                 | secondary | 500     |

单会话与多会话采用相同文字层级，完成或中断通过状态文字和圆点区分；不新增背景块、边框或分隔线。Token 标签使用 tertiary，数值使用 secondary，保留原有 Previous / Task 语义与缺失占位。

收缩态保持现有动态文本测量与宽度计算。主状态具有最高视觉优先级，副标题与主标题通过亮度区分，不改变排列、文案或展示逻辑。

### 4. 主体质感

岛体外边框：

`rgba(255,255,255,0.055)`

顶部内高光：

`inset 0 1px 0 rgba(255,255,255,0.027)`

主体阴影参考：

`0 17px 37px rgba(0,0,0,0.33)`

`0 2px 9px rgba(0,0,0,0.24)`

边框只用于轻微区分轮廓，视觉上不应该形成一圈白色线条。

### 5. 内部卡片

卡片背景：

`rgba(255,255,255,0.018)`

卡片边框：

`rgba(255,255,255,0.05)`

要求：

- 比主体略亮，但不能有明显灰色块感。
- 不添加强阴影。
- 不使用发亮描边。
- 额度卡片保持底部双列排列。

### 6. 资源监控模块

监控栏保持辅助信息的视觉层级。

- CPU / RAM、Desktop / Tasks/CLI 标签：`--text-tertiary`，500 字重。
- CPU / RAM 合计数值：`--text-primary`，600 字重。
- Desktop / Tasks/CLI 占用数值及单位：`--text-secondary`，500 字重。
- 辅助说明：`--text-muted`，400–500 字重。
- CPU / RAM 图标：`#A0ADBC`。
- 桌面端图标：`#7A99AF`
- 任务 / CLI 图标：`#83D6DB`
- 分隔线：`rgba(255,255,255,0.067)`

悬停时可以轻微提高背景亮度和边界对比度，但不出现明显的高亮色块。

监控栏固定显示两行：第一行展示 Codex 桌面端与任务 / CLI 的 CPU、RAM 合计及 CPU 趋势，第二行展示两类进程各自的占用；首行不重复展示内存拆分。两行始终可见，不通过悬停或点击切换。

CPU、RAM、Desktop 和 Tasks/CLI 均使用 12px 单色线性图标，不使用圆点。两行共用固定双列网格；标签、数值及趋势图预留独立槽位，数据变化不会改变列位置。CPU 槽位须完整容纳 `<0.1%` 与 `100%`，内存槽位须容纳 MB、GB 单位及较大数值。

两行数值统一使用 10px、16px 行高和等宽数字，合计为 600 字重，分类明细为 500 字重，单位与数值采用相同字号。CPU 合计与 Desktop 百分比共用右边缘；RAM 合计与 Tasks/CLI 内存共用文字起点，相同格式时单位也须纵向对齐。明细百分比右对齐、内存左对齐，保留固定槽位，避免数值之间出现大段空白。

监控数据更新时文字颜色保持稳定，不因负载变化闪烁。CPU 趋势图保留原有配色及负载语义色，普通负载使用 `#C6D2DE`；不随文字 Token 调整图表颜色、尺寸或采样与交互行为。

### 7. 额度卡片及进度条

百分比及百分号颜色：`--text-primary`（`#F2F6FA`），600 字重；选中与未选中卡片均保持重要数值清晰。

第一张进度条：

`linear-gradient(90deg, #577D8A, #A4CAD3)`

第二张进度条：

`linear-gradient(90deg, #536879, #91A9BD)`

轨道颜色：`#232A32`

进度填充允许非常轻微的柔光，但不可呈现霓虹灯效果。

额度卡片高度 80px，内边距为纵向 13px、横向 12px，标题 / 数值、进度条和重置时间分成三行，行间留白 10px。两张卡片间距 10px；进度条高度 3px。标签使用 13px 的 `5h` 和 `7d`，百分比为 16px；提示保留剩余额度语义。

选中的额度窗口使用 `--text-accent`、600 字重标题，勾选标记、淡青底色和清晰边框保持原有配色。未选中标题使用 `--text-secondary`、500 字重，重置说明使用 `--text-muted`。勾选位置始终预留，切换不改变卡片布局；卡片支持键盘操作，并通过 `aria-pressed` 表达选中状态。不增加发光效果，不调整进度条颜色、长度或厚度。

### 8. 文字扫光

保留现有 **Shimmer Text** 渐变扫光效果，作为基础文字不透明色规则之外的字形内高光叠层；不因文字对比度优化而移除、重写或扩大该效果。

视觉要求：

- 光线从文字左侧移动至右侧。
- 高光只出现在字形内部。
- 采用窄幅、柔和的冷白光带。
- 文字基础颜色始终保持不变。
- 不允许整段文字突然闪白。
- 不增加文字外部的明显发光轮廓。

参考渐变：

`transparent 37% → rgba(237,250,255,.17) 44% → rgba(246,253,255,.93) 50% → rgba(237,250,255,.20) 55% → transparent 63%`

本规范仅定义扫光外观，不规定扫光的状态触发逻辑。

### 9. 图标与装饰

- 图标统一使用单色线性风格。
- 优先冷灰、灰白颜色。
- 参考线宽 1.4–1.6px。
- 活动指示点可以使用微弱冷青色光晕。
- 不新增无意义的光斑、粒子和装饰图案。
- 展开态与收缩态的 Orb 均按 20px 逻辑尺寸直接绘制，通过透明度切换；不将大尺寸画布缩小，避免细节点阵变淡。

### 10. 实施限制

展开态从上到下排列状态栏、项目运行区域、两行资源监控及额度卡片。单项目与多项目共用项目行；每行 50px，最多同时显示 3 行，超出时仅项目区域纵向滚动。展开宽度 380px，高度随项目行数为 306 / 356 / 406px。

每个会话固定两行，行间距 5px。首行左侧为项目名与状态，间距 8px；右侧完整保留耗时。项目名不预留固定宽度，最多占首行左侧文本容器的 42%，状态占剩余空间，两者均单行省略并提供原生悬停提示。第二行左侧为 Token 统计，右侧为模型名称；空间不足先压缩模型，极窄时两项 Token 也可分别截断。模型缺失时留空，Token 保持原有占位，整行点击跳转行为保持不变。

首行项目名、状态与耗时按文字基线对齐，避免不同字号仅按盒子居中造成视觉错位。指示灯属于首行，垂直居中，不通过独立上边距定位；第二行 Token 与项目名共用左起点，模型与耗时共用右边缘，Token 与模型按文字基线对齐。名称保留 16px 行高，状态、耗时及第二行元信息使用 14px 行高；保持两行整体高度和会话行尺寸不变。

项目以 Session ID 区分，同名项目的不同 Session 不合并数据；同一 Session 的运行状态和最近结果只占一行。模型、任务 Token 与会话累计 Token 放在所属项目行中。运行中的 Token 为上次已完成任务的快照，不代表实时累计；无数据时显示缺失或读取状态。

状态机、展开收缩时序、资源采样与 Token 查询触发机制保持现有约定。

文字优化仅允许调整文字颜色、合理字重、原有分区标题的微小字间距、语义化 CSS 变量及与本规范冲突的文字样式。复用现有样式组织方式，不新增 UI 或动画依赖，不手改生成类型，也不引入无关重构。

保持背景、边框、圆角、阴影、尺寸、位置、间距、收缩态动态宽度计算、Orb、进度条、趋势图、状态机、监控取数与交互行为。文案内容与国际化资源不随文字视觉优化修改。

### 11. 验收要求

- 收缩态空闲与运行状态文字清晰，动态宽度正常。
- 展开态 Thinking、任务完成、等待审批的主次层级清晰，特殊状态语义色正确。
- 多会话下易于识别运行任务，完成会话及辅助信息仍然可读。
- CPU、RAM、进程分类监控的小字和数值清晰，更新时文字颜色稳定。
- 5h、7d 的选中与未选中标题、百分比及重置说明均可读。
- 浅色与深色桌面背景下视觉稳定，不因窗口背景混合失去对比度。
- Windows WebView2 在 100%、125%、150% 缩放下没有新增截断、换行或布局偏移。
- Orb、渐变扫光、展开收缩、悬停和状态切换动画保持原有行为。
- 执行项目现有前端检查与测试；浏览器缩放预览和构建通过不能替代 Windows WebView2 实际 DPI 验收。

最终验收重点是：重要文字清晰、辅助文字可读、浅色和深色壁纸下视觉稳定、没有明显白边、各模块层次克制、文字扫光自然，整体保持深空极简风格。
