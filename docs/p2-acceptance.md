# P2 Rust 模块化与 IO 验收

2026-10-15。P2.1–P2.4 代码与自动化检查完成，真实 Windows Hook/托盘联调仍待验收。本次按用户要求继续实施 P3。

## 修改与边界

- `lib.rs` 保留初始化、Managed State、命令与事件组装；启动、托盘、额度 JSON-RPC/解析/调度、窗口定位/点击区、Hook sender/server/protocol、Activity model/reducer/registry 已分离。原测试迁入相应模块，隐藏窗口 subclass 测试保留。
- `HookEventKind` 明确解析 12 种既有事件，reducer 枚举匹配；重复 Prompt、已结束 Turn、迟到 Turn 的守卫保持原条件。Hook ID 兼容旧数据，导航继续只接受 UUID，Token 文件名继续限制安全字符。元数据字段增加长度边界。
- Registry、额度连接和刷新通知改为显式共享 handle，由 Tauri manage/State 持有。后台 Hook 注入 UsageRefresher，无反向调用全局函数；刷新通道容量为 1，合并重复请求。缓存/索引 Mutex 中毒后记录受控日志、清空可重建状态并恢复；工作队列中毒时停止对应工作而非忽略。
- 日志迁到 `~/.codex-limit-island/logs/codexlimit.log`，单文件 1MiB，保留 2 份备份。固定锁文件使用 OS 文件锁，日志句柄在锁内打开和关闭，轮转失败停止本次写入；锁等待最多约 100ms。目录或锁不可用时不阻塞业务，GUI 启动提示日志不可用，stderr 诊断按失败次数的 2 次幂节流。只记录受控阶段/错误类别，不持久化外部错误原文。
- Token 查询使用有界 Session→文件缓存（64 项）、每文件请求过的 Turn 缓存（128 项）、增量偏移；相同 Session 查询串行合并。UUIDv7 先尝试对应日期目录，再兼容搜索其他目录。文件删除、移动、截断、替换或等长改写后重新查找/解析；CODEX_HOME 是索引键的一部分。未完成尾行保留重读，损坏行跳过，超大行有界跳过。
- 保留 taskTokens 为请求 Turn 用量、sessionTokens 为最新会话累计；首次请求较早 Turn 时完整扫描，不以最新 Turn 冒充。所有文件 IO 仍在 spawn_blocking 中完成。完成态 3 秒、Token ready 约 2.8 秒和展开保留规则未改。
- HTTP 已使用固定 8 个工作线程和 16 个排队连接；超额连接返回 503，命令名、事件名、Hook JSON 和正常 204 未变。P3 继续验证整体请求期限和异常资源保护。
